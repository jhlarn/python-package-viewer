# Python Package Viewer

此工具提供圖形使用者介面 (GUI)，使用 PyEDB 探索 EDB (電子資料庫) 檔案。它允許您檢查物件、屬性、方法，並透過 Python 控制台與 EDB 互動。

---

## 安裝

若要設定開發環境並安裝必要的相依套件，請按照以下步驟操作：

1.  **執行安裝腳本**：
    安裝腳本 (Windows 為 `install.bat`，Linux 為 `install.sh`) 將自動檢查並安裝 `uv` (一個快速的 Python 套件安裝程式和管理器)，如果系統中找不到它。接著，如果 Python 虛擬環境 (`.venv`) 不存在，它將建立該環境並安裝所有必要的套件 (包括 `pyedb` 和 `pywebview`)。如果 `.venv` 已經存在，它將更新相依套件。

    *   **Windows**：在終端機中導航至專案目錄並執行 `install.bat`：
        ```shell
        install.bat
        ```

    *   **Linux**：在終端機中導航至專案目錄，使腳本可執行，然後執行 `install.sh`：
        ```bash
        chmod +x install.sh
        ./install.sh
        ```

## 使用方法

安裝完成後，您可以啟動 EDB Explorer GUI：

1.  **啟動 GUI**：

    *   **Windows**：從專案目錄執行 `run.bat`：
        ```shell
        run.bat
        ```
        這將開啟 EDB Explorer 視窗，且不會顯示控制台視窗。

    *   **Linux**：在終端機中導航至專案目錄，使腳本可執行，然後執行 `run.sh`：
        ```bash
        chmod +x run.sh
        ./run.sh
        ```
        這將在背景啟動 EDB Explorer。

2.  **初始 EDB 載入**：
    -   應用程式預設會嘗試載入 `pcb.aedb`。
    -   它會嘗試各種 AEDT 版本 (例如 '2024.1', '2024.2'，直到當前年份) 以尋找相容的安裝。
    -   成功的版本將儲存在 `config.json` 中，以便日後更快載入。

3.  **GUI 版面配置**：
    -   **左側面板**：顯示「全域變數」(已載入的 `edb` 物件和來自控制台的變數)。
    -   **中間面板**：顯示目前選取物件的「物件詳細資訊」(類型、值和格式化的文件字串)。文件字串面板將動態填滿可用空間。
    -   **右側面板**：顯示選取物件的「成員 / 檢查器」(屬性和方法)。它包含一個正規表達式篩選輸入框，用於搜尋成員。
    -   **底部面板**：用於互動式程式碼執行的「Python 控制台」。其可見性可以切換。

4.  **與物件互動**：
    -   **選取物件**：在「全域變數」樹狀圖中點擊物件，以在中間面板顯示其詳細資訊，並在右側面板顯示其成員。物件的路徑將顯示在「目標」輸入欄位中。
    -   **導航成員**：在「成員 / 檢查器」面板中點擊屬性或方法，將其附加到「目標」輸入框並進一步檢查。
    -   **復原/重做導航**：使用「復原」和「重做」按鈕 (位於「目標」輸入框右側) 在您的檢查歷史記錄中導航。

    -   **篩選成員**：使用「成員 / 檢查器」面板中的正規表達式輸入欄位來篩選顯示的屬性和方法。
    -   **右鍵選單**：在「成員 / 檢查器」清單中的任何項目上按右鍵以存取選項：
        -   **列印至控制台**：將項目的值列印到 Python 控制台。
        -   **複製到剪貼簿**：將項目的值複製到您的剪貼簿。

5.  **載入 EDB 檔案**：
    -   **匯入**：點擊「匯入」按鈕開啟檔案對話框，並選取不同的 `.aedb` 資料夾進行載入。
    -   **重新載入**：點擊「重新載入」按鈕關閉目前的 EDB 並重新載入。如果 EDB 檔案在外部已變更，這很有用。每次載入新的 EDB (透過匯入或重新載入) 時，都會呼叫 `edb.close_edb()` 以釋放資源。

6.  **Python 控制台**：
    -   **切換可見性**：點擊頂部欄中的「控制台」按鈕以顯示或隱藏控制台面板。
    -   在底部的輸入欄位中輸入 Python 程式碼。
    -   按 `Enter` 執行。(使用 `Shift+Enter` 進行多行輸入而不立即執行)。
    -   輸出和錯誤將顯示在控制台輸出區域。
    -   **複製輸出**：您可以選取控制台輸出中的文字，並使用 `Ctrl+C` 或右鍵選單進行複製。
    -   在控制台定義的變數 (例如 `my_var = 123`) 將在執行後顯示在「全域變數」面板中。

7.  **可調整的面板邊界**：
    -   拖曳左/中、中/右面板之間，以及主要內容與控制台之間的灰色分隔線，以調整其大小。
    -   您偏好的面板尺寸將自動儲存至 `config.json` 並在啟動時還原。

**設定檔持久性**：大多數使用者偏好設定，包括 AEDT 版本和面板尺寸，都儲存在 `config.json` 中。
