Welcome to Python Package Viewer

1. Initialize an Object

Start by initializing an AEDT object in the Python Console below:

from ansys.aedt.core import Hfss
hfss = Hfss()

Or open an existing design:

from ansys.aedt.core import Hfss
hfss = Hfss('c:\\design.aedt')

Once initialized, the object (e.g., hfss) will appear in the Global Variables panel on the left.

2. Explore & Inspect

  • Click variables in the Left Panel to inspect them.
  • View object details, values, and documentation in this Center Panel.
  • Browse properties and methods in the Right Panel.

3. Drill Down

  • Click on members in the Right Panel to drill down into child objects.
  • Use the Target bar at the top to see the current path.
  • Use Undo/Redo buttons to navigate your history.
